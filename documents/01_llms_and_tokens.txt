Understanding Large Language Models

A Large Language Model (LLM) is a deep learning algorithm trained to predict the
next token in a sequence. LLMs are trained on massive datasets including books,
articles, websites, research papers, and code repositories. Well known examples
include GPT models, Gemini models, and Claude models.

Next Token Prediction
LLMs generate text one token at a time based on probabilities. Given the input
"I like to drink ___", the model considers many possible next tokens such as
"water", "tea", "alcohol", or "juice", and picks based on learned probability
distributions.

Tokens
LLMs process tokens, not words. A token can be a whole word, part of a word, or
punctuation. For example, "ChatGPT is amazing" might be split into tokens like
"Chat", "GPT", "is", "amazing". Tokens matter because context windows and API
costs are both measured in tokens, not characters or words.

The Attention Mechanism
Attention helps a model figure out which words in a sentence are relevant to
each other. Classic example: "The animal didn't cross the road because it was
tired." Attention allows the model to correctly resolve what "it" refers to by
weighing the relationship between "it" and "animal" versus "it" and "road".

The Context Window
The context window is the working memory of an LLM. It typically contains the
system prompt, few-shot examples, available tools, and the full conversation
history (user messages, assistant messages, tool calls and results, and any
retrieved data). Information that exceeds the context window cannot be
processed by the model in that turn.
